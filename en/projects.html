Philosophy of building

Three rules I never break

01

Start from annoyance

The project born from painful repetition at work is the only one that will be finished.

02

Sufficiency is a decision

Building what is enough is not ease, but wisdom. A tool that changes every week is never used.

03

Write before you build

Describe the problem on one page. If you cannot, the project is not ready yet.
